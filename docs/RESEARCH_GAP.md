# Research gap

The papers above already cover pieces of an investigation. PROVSEEK retrieves evidence iteratively and binds claims to provenance ids. CyberSleuth runs a tool-using forensic agent on PCAPs and is scored against CVE gold and expert ratings. GALA+ keeps agents inside a service graph and mixes metrics with traces. GraphRAG and HippoRAG 2 retrieve over graphs built from text. Graphiti stores temporal facts for agent memory. ExCyTIn-Bench, FActScore, and RAGChecker score grounding without letting the writer appoint itself as judge.

None of that is an investigation of an operational-technology window in which the electrical values are themselves decoded from IEC-104. In Sherlock the IPAL state and the dissected ASDU can be two representations of one message. A graph that draws a network node and an electrical node, then treats agreement as multimodal confirmation, double-counts the source. The earlier MIRAGE-OT learned graph did not fix this: on a normal Basic interval the forecast was better with the graph messages removed, so the wiring was not an explanation.

Three gaps remain after those papers:

1. The investigator has to propose relations among network flows, IEC-104 points, and network-reported electrical values, and it has to be allowed to return no cross-modal edge.
2. Revision has to know when two cited rows are the same frame or the same CA/IOA report, and it has to keep the earlier graph instead of overwriting it.
3. A citation has to be tested by removing that record from the judgment, including every derived id, under a fixed seed. The result measures dependence of the model, not causal necessity and not correctness.

Those three are the claims ETGI is built to test. They are not established by the implementation. The Basic case study and the ablations are the test. If an ablation matches the full method on question coverage and on unsupported published edges, the corresponding switch is not a contribution on that window.

A further limit of this project is independence. Basic, Semiurban, and Rural labels have already been visible in earlier work on this dataset, including the event catalog read while choosing clock bounds. The bounds used here do not include the event text, but the window is not unseen. Results are a case study with a predeclared budget, not a confirmatory holdout.
