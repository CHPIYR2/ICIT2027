## 5. Experimental Limitations

1. **No Grid Topology Input**: Because no bus-branch or breaker connectivity model is provided to the engine, cross-device relations (e.g. `switch.13` / `switch.15` opening followed by bus and line de-energizations) cannot be upgraded to topological or causal edges and remain `unresolved` (`4,186` candidate branches across the 28 windows).
2. **Pre-Command / Pre-Report State Baseline Visibility**: In `10` of the `16` control-command windows (and in spontaneous `COT=3` switch reports), the 15-second pre-window slice contains no prior IEC-104 state sample (`COT=20` or `COT=1`) for the binary switch point, or the commanded point is already in the target state (`357` transactions with `no_state_change_observed`, `53` with `state_report_observed_no_pre_baseline`). The consistency gate refuses to claim a verified state transition without both before and after values.
3. **Cross-Vantage Telemetry Discrepancies in Attack Windows**: In windows such as `ev_52f5eee28f8b95e702fd`, `ev_1a2c7b07458620ddeb67`, and `ev_54569eab2d55482f6496`, different switch mirror ports (`n302` vs `n318`) observe conflicting IEC-104 values on the same `apci_tx`. `_merge_iec_vantages()` preserves both conflicting observations and marks `cross_vantage_conflict=True`, which quarantines `671`, `243`, and `222` rapid oscillation anchors respectively as `unverified_observation` so they never corrupt verified bundles or bridges.
4. **Storyline Count Is Not Accuracy**: High storyline counts in windows like `ev_52f5eee28f8b95e702fd` (`675` storylines, `671` of which are quarantined single-node `behavioral_unverified_observation` records) or `ev_343cc5effb0b1b22931b` (`180` command transactions) reflect the volume of raw protocol commands or quarantined oscillations, not reconstruction quality. Only verified transitions (`9` transactions) and corroborated cross-RTU bridges (`6` bridges) represent multi-source supported behavioral transitions.
